# 軒轅劍網路版｜崑崙秘境重製雛形

以初代《軒轅劍網路版》的滑鼠點擊移動、即時戰鬥、快捷技能列、聊天與隊伍介面為基礎製作的瀏覽器可玩雛形。場景和主角使用高解析原創美術，遊戲介面與 NPC／妖怪圖像採平滑向量插畫，保留早期 MMORPG 的介面語彙並避開像素化鋸齒。短音效由 Web Audio 即時合成，無需載入外部音檔。

## 操作

- 滑鼠點地面移動；點 NPC 靠近交談；點怪物接近並攻擊。
- `Q` 攻擊目前目標、`E` 互動、`R` 切換跑步、`Tab` 開地圖。
- `1`–`8` 使用快捷列技能。點擊右上方按鈕可查看背包、地圖與角色狀態。
- 新手任務：先與新生指導員交談，再擊敗兩隻秘境精怪。

## 本機預覽

直接以靜態伺服器開啟專案根目錄，例如 `python -m http.server 8080`，再瀏覽 `http://localhost:8080`。

## Cloudflare Pages

本專案是無建置步驟的靜態網站。將 GitHub 儲存庫 `redfisharthur-beep/Sword-Online` 連接到 Cloudflare Pages，Production branch 設為 `main`，Build command 留空，Build output directory 設為 `.`。之後推送 `main` 即會自動觸發部署。`wrangler.toml` 已標註 Pages 輸出目錄；本次提交不會自行建立 Cloudflare 專案或發布網址。

## 範圍

目前包含角色種族／初始修行選擇、新手村場景、點擊移動、兩種敵人、近戰與法術、生命法力、升級、掉落提示、任務、聊天框、背包／地圖／狀態面板與音效。多人即時連線、帳號、伺服器存檔、完整職業技能樹、其餘地圖與內容需後續擴充。
