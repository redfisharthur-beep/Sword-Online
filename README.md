# 軒轅劍網路版・高解析重製原型

本專案以玩家提供的遊戲畫面和可查到的原作操作資料為參照，重建 4:3 經典 HUD、登入與創角流程、角色狀態、技能列、隊伍、雷達地圖、聊天與角色屬性。場景和角色素材重新繪製為高解析圖片，Canvas 使用裝置像素比繪製，避免舊版低解析素材放大後的鋸齒與色塊。

## 目前可操作內容

- 人類、修羅、天人（仙靈）；原作八職：劍客、魔刀客、刺客、藥師、陰陽師、武術家、修羅醫師、祭符師，並按種族限制可選職業。武術家包含你提出的刀客前衛定位，祭符師包含符咒控場設定。
- 凌水港、廣靈鎮、迷霧森林、陰淮平原、崑崙山、巨石林、長城平原、赤壁沙漠、九曲結界、龍棲山、靜咫鎮雙狀態、冰封之谷、天外天、幽冥界、通天塔等區域，以及各區域怪物清單。
- 點地移動、選怪、Q 攻擊、R 自動奔跑、方向鍵微調視角、滾輪縮放；1–8 施放技能，技能列可切換 10 頁並把技能編入其他頁。
- 技能重複施放累積熟練；空白鍵或 `/sit` 打坐回復 HP／MP 並修練冥思。
- 任務日誌、亂世真情稱號獎勵、稱號加成、角色屬性、職業／種族限制裝備、麻布包裹擴充、招魂號角與法寶戰鬥經驗升級。
- 程序合成戰鬥音效；進度保存在瀏覽器 `localStorage`。

## 本機預覽

專案根目錄執行 `python -m http.server 8080`，再開啟 `http://localhost:8080`。

## Cloudflare Workers 部署

`wrangler.toml` 已使用 Workers Static Assets 指向專案根目錄，無需建置步驟。在 Cloudflare Workers Builds 中設定：

- Production branch：`main`
- Root directory：`/`
- Build command：留空
- Deploy command：`npx wrangler deploy`

將變更推送到 `main` 後，已連接的 Workers Build 專案會自動部署至其 Worker 網址（需在 Cloudflare 帳戶中啟用 workers.dev 或綁定網域）。

## 重製範圍

這是可在瀏覽器遊玩的單機原型，沒有原作伺服器、帳號、多人同步或原作客戶端的模型／動畫資料；圖片素材為依截圖重新製作，完整任務文字、怪物數值、技能平衡與所有原作地圖仍需逐項依可取得的原始遊戲資料校準。原作技能和職業以舊版官方／遊戲資料記載名稱為準；使用者提出的職能描述已納入相應職業設計。
