# 原始檔案解碼與現況

已取得使用者提供的兩份壓縮檔（不存放於公開 GitHub 儲存庫）：
- MODEL.zip：6,173 項，包含 5,510 個 .PLY、468 個 .S3D、64 個 .WLD、7 個 .ACT。
- TEX.zip：7,613 項，包含 3,530 個 .TEX、3,282 個 .TSW、601 個 .WAV、79 個 .MP3、42 個 .S3D。

已讀取原始檔頭：
- Build/00across01mk.S3D：開頭 `SS3D`
- MODEL/MAP00001.WLD：開頭 `WLD\0`
- MODEL/ALL_CHAR.IDX：開頭 `IDX_PLY\0`
- CHR00001.PLY 並非標準 Stanford PLY，不能直接交給通用 PLYLoader。
- TEX/ALL00001.TEX 並非一般 PNG、DDS 或 JPEG，仍需釐清專有壓縮格式。

注意：上述是**真實檔案結構盤點**，尚未解出可直接使用的原版人物骨架、網格與貼圖。當前 world3d.js 仍是過渡性立體幾何；不可稱為原版高還原。

本次互動改善：
- 手機搖桿控制角色；點地不自動走。
- 攻擊可自動選取當前怪物，且有近戰距離限制。
- 長按普攻重複觸發；點擊 3D 怪物可選取。
- 3D 任務提示顯示當前場景內的相對方位與估算距離，不代表已解碼原版任務座標。

下一階段：以格式解碼和真實遊戲資源替換代理模型為優先，而非增加更多佔位素材。
