# 內容來源與重製界線

重製方向：保留經典4:3構圖、綠金介面與鍵鼠操作，提升可讀性及場景解析度。現有場景、角色和戰鬥仍是瀏覽器重製原型，不是原版客戶端或完整原版伺服器。

## 已核對的資料入口

- [2023chain](https://sites.google.com/view/2023chain)：讀取新手、寵物、裝備、技能任務與相關網站內容。
- [亂世真情1–5](https://sites.google.com/view/2023chain/技能任務/亂世真情任務1-5)：包含NPC座標、任務道具、前置與限時條件，尚未完整實作。
- [17173道具索引](https://swdol.17173.com/item/item.htm)：讀取裝備分類、地區商店與掉寶索引；完整子頁仍需逐項校對。
- 玩家提供的登入截圖：青綠雲海、懸空城池、橋樑與標誌構圖參考。登入美術屬重製，並非原版素材。

2023chain包含「鏡之界」自訂裝備、GM福利與規則；不將這些數值標為官方原版。部分圖片或地圖連結無法讀取，Google Sheets只確認入口，未宣稱完整資料匯入。

角色建立、地圖切換、移動、戰鬥、技能、打坐、商店、包裹擴充、物品回復、經驗升級、本機存檔及匯出匯入。「港口的異聲」只計入凌水港的水鬼與軟泥怪。雜貨舖價格、金幣掉落與回復量為本原型的遊玩設定，尚未驗證為官方數值。
