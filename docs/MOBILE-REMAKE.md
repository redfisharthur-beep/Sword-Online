# 手機單機版控制器 - 2026-10-21
本分支為既有遊戲增加觸控操控層，不改寫原始戰鬥與存檔核心：
- 左側虛擬搖桿映射 WASD，手動移動；不啟用自動導航。
- 右側普攻 Q、技能 1–3、任務 F3、背包 F4。
- 右上提供 Fullscreen API 按鈕；iOS 部分瀏覽器不支援沉浸式全螢幕。
- 任務提示目前僅為可開啟任務清單的方向提示佔位，尚無各任務的實際路徑座標。
- 保留既有原版職業、怪物與裝備原型；原始 MODEL/TEX 格式尚未成功解析，不宣稱為真實原版 3D 復刻。
