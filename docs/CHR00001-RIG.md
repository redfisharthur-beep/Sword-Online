# CHR00001 原版骨架動畫新發現

從已 LZO1X 解壓的 `MODEL/CHR00001.PLY`，在 byte offset **19916** 找到**連續 2681 個**符合齊次 4×4 矩陣的 64-byte 區段。每個矩陣最後一行皆為 `[0,0,0,1]`，前三行第 4 欄為真實原始空間位置。

以 **44 個矩陣為一組**，相鄰組的關節位置高度相似（44 stride 平均差異遠小於 43、45 stride），因此可辨識至少 **60 組完整姿態 × 44 個節點**，並從資料直接擷取位置以展示連續動作。原始 FPS、關節名稱、父子關係仍不明，展示播放器的速度只是暫定。

可重現：

```bash
python3 scripts/decode_original_assets.py MODEL.zip MODEL/CHR00001.PLY --out CHR00001.bin
python3 scripts/export_original_rig.py CHR00001.bin --out CHR00001_rig_frames.json
```

**這是真正原始動作變換矩陣的還原，不是已完成的角色模型。** 網格頂點、三角面、UV、貼圖索引、蒙皮權重還沒有正確解析，無法宣稱已還原原版人物 GLB 或完整動作綁定。不可用程序生成角色替代。

獨立可旋轉關節預覽 ZIP 已交付使用者，顯示 44 個原始節點的 60 組連續姿態，並附上兩張已解碼的 TEX 素材（**尚未證實是這個角色的貼圖**）。
